Acceptable use

Pack is intended to reduce repetitive user-directed document collection, not to create unattended scraping or unauthorised access.

Allowed use

  • Downloading supported filed GSTR‑3B PDFs, filed GSTR‑1 summary PDFs, and optional GSTR‑1 e-invoice details Excel files from GST accounts you are authorised to access.
  • Testing Pack with synthetic data or a separate browser profile.
  • Reviewing, contributing to, or reporting issues in the public source repository.

Not allowed

  • Attempting to bypass GST Portal login, OTP, CAPTCHA, authorisation, or access controls.
  • Submitting real GST credentials, cookies, session tokens, portal HTML, or downloaded GST files to public issues.
  • Using Pack for advertising, lending, creditworthiness, profiling, or unrelated data collection.
  • Representing Pack as an official GSTN, CBIC, or government tool.
