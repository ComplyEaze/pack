Pack support

Support works best when reports are reproducible, synthetic, and free of taxpayer data.

Common help

Most issues come from browser profile state, expired GST Portal sessions, unsupported portal pages, or Chrome download settings.

Pack cannot find my GST tab.

Open a supported GST Portal page in the same browser profile, then reopen Pack.

My GST Portal session expired.

Sign in again directly on the GST Portal and restart the supported Pack flow.

The requested return is not visible.

Confirm the return is filed and visible for the chosen financial year and period.

The download did not begin.

Check Chrome's download shelf, the configured download folder, and site download permissions.

Chrome blocked multiple downloads.

Allow downloads for the GST Portal when you intentionally request multiple files.

I need to clear local Pack data.

After active or unresolved recovery state is resolved, open Pack options and use Clear local Pack data. Removing the extension or browser profile is the fallback for extension-local state.

Do not send sensitive material

Public issues, email, screenshots, and private reports should use synthetic or redacted data unless ComplyEaze explicitly requests another secure channel.
  • GSTIN, PAN, Aadhaar, taxpayer names, client names, or trade names.
  • Passwords, OTPs, CAPTCHA responses, cookies, session tokens, or credentials.
  • ARNs, return values, tax amounts, downloaded GST files, real filenames, portal HTML, headers, cookies, raw network captures, or unredacted screenshots.

Contact routes

Public bug or docs issue

Use GitHub issues only if issue creation is available to you. Include synthetic reproduction steps and no GST identifiers.

General support

Email contact@complyeaze.com with redacted, non-sensitive context.

Private security report

Email security@complyeaze.com; never file public security issues.
